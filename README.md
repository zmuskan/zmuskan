### [ANSME](https://github.com/zmuskan/ANSME)

**Product Intelligence & Comparison Engine**

A product decision-support application that extracts product information from URLs and compares alternatives using structured analysis, deterministic scoring, and explainable verdicts.

**Core Work**

- Web-based product information extraction
- Custom scoring and verdict logic
- Pairwise product comparison
- Price and rating analysis
- Backend API integration and validation
